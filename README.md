# CS360

The goal of my app was to help users keep track of events in an easy and organized way. It was designed to meet the need for a simple tool where users can add, view, and manage their events without confusion.

To support this, the app included basic screens like a main screen to display events and another screen to add new ones. I focused on keeping the layout clean and easy to understand, with clear buttons and simple input fields. This helped make the app user-friendly, so anyone could use it without needing instructions. The design was successful because it avoided clutter and made navigation straightforward.

When coding the app, I took it step by step, working on one feature at a time instead of trying to do everything at once. I also reused code when possible and made small improvements along the way. This approach can be useful in the future because it keeps projects organized and easier to fix if something goes wrong.

To test the app, I ran it often and checked each feature to make sure it worked correctly, like adding and displaying events. This process is important because it helps catch errors early and makes sure the app actually works for users. It also showed me where I needed to fix bugs or improve the design.

During development, I had to be creative when fixing errors and making sure different parts of the app worked together properly. Sometimes things didn’t work as expected, so I had to try different solutions until I found one that worked.

One area where I was most successful was creating a simple and clean user interface. It showed that I understand how to design an app that is easy to use while still meeting the main goal of the project.
